# RAFAELIA ZERO — operational evidence gate

## Purpose

This gate converts one debug-device execution into bounded, auditable evidence
without confusing static validation with physical proof.

```text
source contract
→ debug APK
→ guarded adb probe
→ native RFZ1 ingest
→ atomic app-private receipt
→ installed APK capture
→ transcript + SHA-256 bindings
→ atomic evidence bundle
→ validated per-role selection
→ ARM32/ARM64 matrix
```

The source tree starts with both required roles in `TOKEN_VAZIO`. Only physical
bundles may change the generated matrix state.

## Authority

```text
runtime
  app/src/main/java/com/termux/app/rafaelia/RafaeliaZeroRuntime.java
  rafaelia/src/main/cpp/zero/rafz.c

  scripts/validate_rafaelia_zero_device_matrix.py
```

## Required targets

| Role | Native ID | Expected ABI | Intended project device |
|---|---:|---|---|
| `arm32-legacy` | `1` | `armeabi-v7a` | Moto E7 / Android 10 |
| `arm64-modern` | `2` | `arm64-v8a` | Realme Note 50 |

The device names are intentions, not evidence. Until captured:

```text
arm32-legacy = TOKEN_VAZIO
arm64-modern = TOKEN_VAZIO
matrix = TOKEN_VAZIO
```

## Execute

From the repository root, with a local debug APK:

```bash
bash scripts/run_rafaelia_zero_device_probe.sh \
  path/to/termux-rafcodephi-debug.apk
```

With a debuggable APK already installed:

```bash
bash scripts/run_rafaelia_zero_device_probe.sh
```

The runner always resolves the installed package using `pm path` and captures
the exact installed `base.apk` using `adb pull`.

When an input APK is provided, the runner requires:

```text
SHA256(input APK) == SHA256(installed APK captured from device)
```

It also requires exactly one installed APK path. Split-package ambiguity is
rejected rather than silently hashing only part of an installation.

## Fail-closed conditions

The run fails when any of the following occurs:

- `adb`, Python or `mktemp` is unavailable;
- no target is connected;
- `run-as` cannot prove a debuggable package;
- the guarded probe cannot start;
- the receipt does not appear;
- receipt validation fails;
- serial, fingerprint or APK path is empty;
- more than one installed APK path is returned;
- installed APK capture fails;
- input and installed APK hashes differ;
- bundle creation or validation fails;
- selected matrix reconstruction fails.

Transcript capture preserves the real command exit status. Piping output through
`tee` cannot convert a failing command into success.

## Evidence bundle

Each successful run creates:

```text
build/reports/rafaelia-zero/evidence/<timestamp>-<serial>/
├── receipt.json
├── capture.json
├── transcript.txt
├── apk.bin
├── manifest.json
└── SHA256SUMS
```

### `receipt.json`

Generated by the debug probe inside app-private storage. It records:

- package and device fingerprint;
- process architecture and page size;
- native architecture ID;
- init and ingest status;
- null and range guards;
- accepted/rejected counters;
- state digest before and after.

### `capture.json`

Generated on the host and cross-checked with the receipt:

```text
capture.package == receipt.package
capture.device_fingerprint == receipt.device.fingerprint
```

It also records device serial, installed APK path and capture timestamp.

### `transcript.txt`

Must contain:

```text
RAFAELIA_ZERO_DEVICE_PROBE=PASS
receipt_sha256=<exact digest>
apk_sha256=<exact installed APK digest>
```

The builder rejects a transcript not bound to both files.

### `manifest.json`

Contains the normalized role, runtime summary, device identity, file sizes and
SHA-256 digests. One valid bundle may declare:

```text
claim_allowed_device_single = true
```

It must retain:

```text
claim_allowed_device_matrix = false
release_claim_allowed = false
independent_reproduction = TOKEN_VAZIO
```

### `SHA256SUMS`

Covers the four payload files and `manifest.json`. The validator rejects:

- missing or additional files;
- empty files;
- symlinks;
- malformed sums;
- hash or size divergence;
- role/architecture disagreement;
- capture/receipt identity disagreement;
- transcript/hash disagreement.

## Atomic publication

A bundle is assembled under:

```text
.<bundle>.tmp-<pid>
```

Only after manifest and hashes are complete is it promoted by atomic directory
rename. Matrix files and selection pointers use `temp + fsync + replace`.

An interrupted staging directory is not a published bundle.

## Canonical selection

Historical bundles are preserved. The matrix consumes only one validated bundle
per role through:

```text
selected-arm32-legacy.txt
selected-arm64-modern.txt
selected-x86.txt
selected-x86_64.txt
```

Each pointer contains only a direct-child bundle name. The rebuilder rejects:

- absolute or traversing paths;
- `/`, `\`, `.` or `..` payloads;
- pointer symlinks;
- bundle symlinks;
- bundles outside the evidence root;
- a bundle whose measured role differs from the requested role.

A new successful run updates only the pointer for its role. Previous bundles
remain available for audit and rollback.

Manual selection/rebuild:

```bash
python3 scripts/rebuild_rafaelia_zero_device_matrix.py \
  --evidence-root build/reports/rafaelia-zero/evidence \
  --select-role arm32-legacy \
  --select-bundle build/reports/rafaelia-zero/evidence/<bundle>
```

## Promotion state machine

```text
no required selected bundle
→ TOKEN_VAZIO
→ claim_allowed_device_matrix=false

one required selected bundle
→ PARTIAL_DEVICE_PROOF
→ claim_allowed_device_matrix=false

one distinct ARM32 bundle + one distinct ARM64 bundle
→ DUAL_ARM_DEVICE_PROOF
→ claim_allowed_device_matrix=true
```

The canonical matrix rejects duplicate role, receipt digest, serial or
fingerprint. Equal APK hashes are allowed because the same universal APK may be
measured on both architectures.

Even in `DUAL_ARM_DEVICE_PROOF`:

```text
release_claim_allowed=false
independent_reproduction=TOKEN_VAZIO
```

Debug evidence does not attest a release build or third-party reproduction.

## Static gate

No new GitHub Actions workflow is created. The existing chain is extended:

```text
Rafaelia Native Safety
→ scripts/verify_rafaelia_native_safety.py
→ scripts/validate_rafaelia_zero_runtime.py
→ scripts/validate_rafaelia_zero_device_probe_contract.py
→ receipt adversarial self-test
→ bundle builder self-test
→ bundle validator tamper tests
→ matrix state/anti-replay self-test
→ selection/path traversal self-test
```

Static success proves the measuring instrument and rejection logic only. It does
not promote either physical-device role.

## Manual validation

One bundle:

```bash
python3 scripts/validate_rafaelia_zero_device_bundle.py \
  build/reports/rafaelia-zero/evidence/<bundle>
```

Selected matrix:

```bash
python3 scripts/rebuild_rafaelia_zero_device_matrix.py \
  --evidence-root build/reports/rafaelia-zero/evidence
```

All static/adversarial contracts:

```bash
python3 scripts/validate_rafaelia_zero_device_probe_contract.py
```

## Epistemic boundary

```text
instrument implemented                FATO
static adversarial path implemented   FATO
installed-artifact sealing path       FATO
physical ARM32 bundle                 TOKEN_VAZIO until captured
physical ARM64 bundle                 TOKEN_VAZIO until captured
dual-device matrix                    TOKEN_VAZIO until both validate
release artifact proof                TOKEN_VAZIO
independent reproduction              TOKEN_VAZIO
```

Operational excellence is not a decorative green state. It is knowing exactly
which artifact ran, where it ran, what changed, how evidence is sealed, how a
selection can be rolled back and what remains unproved.
